## Highlights

The first week gathered against the Hydra repositories: 9 PRs merged, 7 issues
closed and 48 commits, almost all of it in `cardano-scaling/hydra`.

**Performance (M2).** The fanout benchmark now varies the number of parties
(#2796), giving a curve rather than a single data point. Two `PersistentQueue`
bugs were closed — the queue blocked when full with no visibility (#2688) and
`popPersistentQueue` only popped when `next == item` (#2689) — and an open PR
makes `rejectLowDeposits` a single pass instead of O(n²) (#2805).

**Maintenance and DevX (M5).** The bulk of the week. Two correctness fixes
landed on the deposit path: deposits too large to be claimed by an increment
transaction are now rejected (#2807), closing a case where a deposit could be
accepted and never redeemed, and a new `--deposit-activation` flag (#2802)
decouples activation from the deadline calculation.

Release packaging moved forward: macOS release binaries run without Nix (#2795),
closing the AArch64 Darwin issue where shipped binaries linked against
`/nix/store` paths absent on a user's machine. A follow-up came in from the
field — the 2.3.0 Docker image fails on Apple Silicon while the native binary
and Linux both work (#2812) — and a PR to publish `linux/arm64` images is open.
The long-running-node era-history bug (#2798), where a node silently stopped
accepting Plutus transactions with future validity bounds, was also closed.

Test reliability got a pass (flaky generators merged, a broader etcd/TUI/
chain-sync flake fix opened), a PR opened to make etcd fail fast when peer
configuration changes (#2804), and on docs a partial-fanout page shipped
alongside fixes to dark mode, benchmark-page rendering and version links
(#2799).

**On attribution.** 21 of 23 items carried a workstream milestone this week, up
from 1 before the milestones were reorganised. The two that didn't: a Plutus
time-conversion fix with no milestone (#2803), and a partial-fanout check still
filed under the retired `MS 6.5` milestone (#2461). Both sit in the Reactive
bucket, as do the week's raw commit counts, which carry no milestone by nature.
Operational Excellence (M3) and Ecosystem Support (M4) saw no activity this
week.
